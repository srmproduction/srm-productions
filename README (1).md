## Editing contact details

Open `index.html` and edit the `CONFIG` block near the bottom of the file (email, phone, WhatsApp number, Instagram). The page updates automatically.

## Deploying

1. Upload `index.html` to this repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then save.
4. The site goes live within a few minutes.

To use a custom domain, add it under **Settings → Pages → Custom domain**.
